# VLD Colab tutorial

A hands-on notebook that generates contingency data for pandapower's `case33bw`, derives and tunes `VLDTopologyLoss` on a five-bus example, trains a small model and runs inference with a pre-trained checkpoint.

Notebook and companion files: `examples/tutorial_vld/` ([README](https://github.com/gridfm/gridfm-app-distribution/tree/main/examples/tutorial_vld)).

Open `examples/tutorial_vld/Tutorial_vld_colab.ipynb` in Google Colab, select a T4 GPU runtime and run top to bottom.
