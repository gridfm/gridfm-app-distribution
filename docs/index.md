# GridFM App Distribution

GridFM App Distribution provides applications for electricity distribution use
cases within the GridFM ecosystem.

The project is at an early stage. Add user-facing guides under `docs/manual/`
and API/component documentation under `docs/components/` as functionality is
introduced.

This library contains specialised tasks for electricity distribution applications.
