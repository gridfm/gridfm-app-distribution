# Getting Help

There are several ways to connect with the GridFM project:

- Join the GridFM community and subscribe to the monthly meetings at
  [gridfm.org](https://gridfm.org).
- Report bugs or request features in the
  [gridfm-app-distribution issue tracker](https://github.com/gridfm/gridfm-app-distribution/issues).

Do not report security vulnerabilities in a public issue. Follow the private
reporting process in [SECURITY.md](SECURITY.md).

To contribute a fix, follow [CONTRIBUTING.md](CONTRIBUTING.md).
